번호 요소명 유형 표시 내용 동작
1 기본 정보 요약 정보 작성자, 작성일, 현재 진행 상태를 표시한다. 사용자가 입력하지 않으며 현재 문서 상태에 따라 갱신된다.
2 지출 내역 입력 표 사용일, 지출 유형, 거래처, 금액을 행 단위로 표시한다. 행을 추가하거나 삭제하면 합계 금액을 다시 계산한다.
3 문서 행동 버튼 임시 저장, 지출결의 제출 행동을 표시한다. 제출 전 필수값과 증빙 등록 여부를 확인한다.
