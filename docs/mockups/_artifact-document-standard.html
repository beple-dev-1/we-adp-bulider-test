기능 명세

기능 ID 기능명 입력·조건 처리 내용 처리 결과
FN-001 지출 내역 입력 사용일, 지출 유형, 거래처, 금액을 입력한다. 필수값과 금액 형식을 확인하고 합계 금액을 다시 계산한다. 정상 입력값을 지출 내역에 반영한다.
FN-002 작성 내용 임시 저장 제목과 한 건 이상의 지출 내역이 입력되어 있다. 현재 입력값과 첨부된 증빙 정보를 임시 상태로 저장한다. 저장 시각을 표시하고 사용자가 계속 작성할 수 있게 한다.
FN-003 지출결의 제출 필수값과 증빙이 모두 등록되어 있다. 누락 항목과 합계 금액을 확인한 뒤 결재 요청을 등록한다. 요청 번호를 안내하고 지출결의 상세 화면으로 이동한다.

입력 및 업무 규칙

항목 필수 입력 규칙 오류 안내
사용일 필수 오늘보다 늦은 날짜를 선택할 수 없다. 사용일은 오늘 이전 날짜로 선택해 주세요.
금액 필수 0보다 큰 원 단위 정수만 입력한다. 금액은 1원 이상으로 입력해 주세요.
증빙 조건부 필수 지출 유형에 따라 증빙 등록 여부를 확인한다. 선택한 지출 유형에 필요한 증빙을 등록해 주세요.

업무 규칙: 제출에 실패하면 입력 내용은 유지하고, 문제가 있는 항목 가까이에 이유와 다음 행동을 함께 표시한다.
