# AI 초벌이 마음에 안 들 때 기획자는 무엇을 하나

> **이 문서가 답하는 질문 하나: AI 가 만들어 낸 초벌이 마음에 안 들 때 기획자가 무엇을 하나.**
> 초벌을 어떻게 만드나는 여기 없다 — 그건 `ai-run` 이다. 무엇을 만드나도 여기 없다 — 그건 `intake`·`brd`·`handoff-to-dev` 다.

**「초벌」은 AI 가 층을 넘기며 처음 만들어 내는 것이다.** 다섯 갈래 중 넷이 초벌을 만든다.
⚠️ **「BRD 초안」과 헷갈리지 마라** — 그건 산출물 이름이고, 초벌은 만들어지는 방식을 가리키는 일반 명사다.

---

## 무엇이 비어 있었나

`ai-run` 이 실행 갈래를 다섯으로 적어 뒀는데, **그 다섯이 같은 층위가 아니다.**

| 층 전이 | 갈래 | 무엇인가 |
|---|---|---|
| 받은 문서 → 요구사항 | 요구사항 뽑기 | **초벌을 만든다** |
| 요구사항 → 요구사항 정의서 | 정의서 쓰기 | **초벌을 만든다** |
| 정의서 → BRD | BRD 초안 | **초벌을 만든다** |
| 작업 목업 → 개발요청서 | 개발요청서 쓰기 | **초벌을 만든다** |
| BRD → 작업 목업 | 목업 고치기 | ⛔ **초벌이 아니다 — 사람이 말로 고치는 반복 루프다** |

한 목록에 섞여 있어서 안 보였다. 그리고 **초벌 넷에는 「마음에 안 들 때」가 없다.**

앞선 문서 둘이 그 필요를 이미 적어 뒀는데 돌릴 기계가 없었다.

- `intake-design.md:130` — 「사람은 … **AI와 대화해** 의도·범위·용어를 다듬는다.
  AI 제안은 **사람이 적용하기 전까지 현재 초안을 덮어쓰지 않는다**」
- `ia-design.md:276` — 「`[ 내용 수정 ]` 을 누르면 … **AI 대화는 본문 위 오버레이**로 뜬다」

`ai-run` 전체에 **「대화」가 0건**이다. 이 문서가 그 자리를 세운다.

## 트랙이 둘이다 — 가르는 기준은 「파일을 고치나」 하나다

나머지가 전부 거기서 따라 나온다. **기준을 둘로 두지 마라** — 하나로 두었기 때문에 아래 표의 모든 칸이 저절로 정해졌다.

| | **일 트랙** (초벌) | **대화 트랙** (상의) |
|---|---|---|
| 파일 | **고친다** | ⛔ **안 고친다** |
| 도구 | Edit · Write 허용 | ⛔ `Read` · `Grep` · `Glob` 만 |
| 명령 | `-p --output-format json` | `-p --output-format stream-json --verbose` |
| 기다리는 동안 | 진행 표시만 | 답변 글자 + 도구 활동 |
| 스냅샷 | 찍는다 | **안 찍는다** — 되돌릴 파일이 없다 |
| 잠금 | 건다 | **안 건다** |
| 「한 일에 하나」 유일 제약 | 걸린다 | **안 걸린다** — 여럿이 동시에 상의해도 된다 |
| 결과가 앉는 법 | 파일에 바로 | **사람이 「적용」을 눌러야** |

⭐ **대화 트랙은 스냅샷·잠금·되돌리기 장치를 하나도 안 쓴다.**
그 장치들이 있는 이유가 「AI 가 파일을 고친다」 하나뿐이기 때문이다.

⛔ **도구 제한이 이 설계의 뼈다.** 「안 고친다」를 코드의 성실함으로 지키는 것이 아니라
**프로세스에 쓰기 도구를 아예 안 줘서** 지킨다. `intake:130` 의 「적용 전까지 덮어쓰지 않는다」가
장치 없이 참이 된다.

### 대화 트랙이 붙는 자리

| 갈래 | 일 트랙 | 대화 트랙 |
|---|---|---|
| 요구사항 뽑기 · 정의서 쓰기 · BRD 초안 · 개발요청서 쓰기 | 있다 | **있다** |
| 목업 고치기 | 있다 | ⛔ **없다** |

⛔ **목업 작업대에 대화 트랙을 붙이지 않는다.** 거기는 「고쳐줘」가 곧 일이고,
**문맥만 이어지면 「아니 그거 말고」가 통한다.** 따로 상의할 자리가 필요하다는 근거를 아직 못 봤다.

⚠️ **`AiRunKind` 에 값을 더하지 마라.** 갈래는 다섯 그대로 두고 **축을 하나 더한다.**
값으로 더하면 다섯이 열이 되고, 끝 다섯 갈래·스냅샷·유일 제약이 열 벌로 갈라진다.

## 문맥의 정본은 빌더 DB 다

```
매 실행마다 빌더가 프롬프트를 조립한다
  ├─ 지금 산출물 본문
  ├─ 지금까지의 지시·대화 이력  (되돌린 것은 빠진 채로)
  └─ 이번에 사람이 쓴 것
        ↓
   claude -p   ← 기억이 없다. 매번 빌더가 주는 것만 안다
```

⛔ **`-r <session-id>` 를 쓰지 않는다.** Claude 세션 파일에 문맥을 맡기면 셋이 깨진다.

| 무엇 | Claude 세션(`-r`) | 빌더가 조립 |
|---|---|---|
| 되감기 | ⛔ **못 한다** — 끝에서만 이어붙는다 | **된다** — 이력에서 빼면 그만 |
| 무엇이 갔는지 | 모른다 | **안다** |
| 세션 파일 수명 | 자격 자리 수명과 얽힌다 | **상관없다** |

⭐ **세 번째가 이미 나간 코드를 지킨다.** `AiRunWorker.java:102` 가 자격 자리를 실행마다
`finally` 로 통째로 지우는데, 세션 파일이 그 안에 산다. `-r` 에 기댔으면
**대화 한 마디마다 세션이 지워져** 이어붙일 것이 없었다. **그 코드를 안 건드려도 된다.**

⭐ **문맥을 골라 실을 수 있어서 더 싸다.** `-r` 은 도구 호출 로그와 중간 과정까지 다시 싣는다.
빌더가 조립하면 **지시와 결과만** 고른다.

**재료는 이미 예약돼 있다** — `ai-run` 이 「한 일에서 보낸 지시를 순서대로 보관한다.
성공한 것도 남긴다」로 표 하나를 잡아 뒀다. 그것을 문맥의 정본으로 쓴다.

## 대화 한 번이 도는 모양

```
   기획자가 쓴다
        │
   빌더가 프롬프트를 조립한다          ← 본문 + 이력(되돌린 것 뺀 채) + 이번 말
        │
   claude -p  (읽기 도구만 · 스트리밍)
        │
   ┌────┴──────┐
답변만 왔다   수정본이 왔다
   │              │
대화가 이어진다   [ 적용 ]  [ 계속 대화 ]
                    │
              빌더가 초안 본문을 갈아끼운다   ← ⛔ Claude 가 아니라 빌더가 쓴다
```

### 적용 — 쓰는 것은 빌더다

**AI 는 수정본을 대화창에 낼 뿐이고, 파일에 앉히는 것은 빌더다.**

⭐ **그래서 되돌리기가 「이전 판으로」 한 줄이 된다.** 빌더가 무엇을 썼는지 정확히 알기 때문에
스냅샷 장치가 아예 안 든다. AI 가 직접 고쳤으면 무엇이 바뀌었는지 모르니 스냅샷이 필요했다.

⚠️ **대화 한 턴의 시간 상한은 일 트랙과 같은 값을 쓴다.** 따로 두지 않는다 —
같은 `claude -p` 프로세스이고, 다른 값을 둘 근거가 없다.

## 되돌리기 — 지시 이력에서 지점을 고른다

작업대 오른쪽 「지난 지시」 칸이 그대로 이 자리가 된다.

```
  [ 맨 처음으로 ]              ← 이것이 「다시 시작」이다
  1. 제목 칸을 필수로
  2. 임시저장 버튼 추가          [ 여기로 ]
  3. 표를 카드로 바꿔줘          [ 여기로 ]
```

⭐ **개념이 하나다.** 「다시 시작」은 지점을 맨 위로 고른 것일 뿐이라 설명할 것이 하나다.

고르면 **둘이 한꺼번에 움직인다.**

1. 파일을 그 지점 스냅샷으로 되감는다
2. 문맥에서 그 뒤를 뺀다

⛔ **둘을 한 트랜잭션으로 묶어라.** 어긋나면 **파일과 문맥이 다른 시점을 본다** —
사람은 되돌아간 화면을 보는데 AI 는 안 되돌아간 이야기를 안다.

**뺀 뒤 새 지시를 하면 거기서부터 다시 쌓인다.**
⛔ **「다시 앞으로」(redo)를 만들지 않는다** — 되돌리기의 되돌리기까지 두면 개념이 둘이 된다.

⛔ **되돌린 지점 이후를 다시 실행해서 복구하려 하지 마라.** AI 는 같은 지시로 같은 결과를
안 낸다. **기획자가 안 건드린 데가 바뀌어 있는 것이 더 무섭다.** 스냅샷으로 되감는 것이 확정적이다.

### 스냅샷은 새로 안 든다

**실행마다 순번 디렉토리가 이미 쌓이고 있다.** 「여기로」가 그 순번을 가리킬 뿐이다.
디스크 값은 이미 치르고 있었고, 없던 것은 화면과 판정이다.

⚠️ **`planner-one-flow` 의 「되돌리기 한 칸 · 이력 목록까지는 과하다」를 이 문서가 뒤집는다.**
그 판단은 **문맥이 없던 전제**에서 나왔다. 지금은 지시 이력이 어차피 문맥의 정본이라
줄로 서 있고, 재료가 다 있는데 화면만 안 주는 꼴이 된다.

### 되돌리기가 둘인 것을 헷갈리지 마라

| | 누가 | 언제 |
|---|---|---|
| **자동 되돌리기** | 빌더 | 실행이 실패·시간초과·그만둠·자격끊김으로 끝났을 때 |
| **여기로 돌아가기** | 기획자 | **성공했는데 결과가 마음에 안 들 때** |

**이 문서가 세우는 것은 둘째뿐이다.** 첫째는 `ai-run` 것이고 안 건드린다.

## 화면 — 새로 그릴 것이 하나다

| 어디 | 무엇 | 있나 |
|---|---|---|
| 산출물 상세 (요구사항 · 정의서 · BRD · 개발요청서) | 대화 오버레이 | **자리는 이미 정해져 있다** — `ia-design.md:276` |
| 목업 작업대 | 지시 칸 · 지시 이력 | **이미 있다** |

**상세에 다시 들어오면 고른다 — 「이전 대화 이어가기」 / 「새로 시작」.**

⭐ **이것이 가능한 까닭이 「문맥의 정본은 빌더 DB」다.** Claude 세션에 맡겼으면
그 세션이 언제 죽는지 우리가 모르니 이 선택지를 줄 수 없다.

**대화 수명은 일이 닫히면 같이 지운다.** `ai-run` 이 지시 보관에 이미 정해 둔 규칙과 같다 —
새 규칙을 만들지 않는다.

## 기다리는 동안 무엇이 보이나

`ai-run` 이 인용해 둔 결정이 하나 있다 — **「스트리밍은 기획자에게 개발 언어를 그대로 노출한다」.**
**대화 트랙은 그 금지를 넘는다.** 넘어도 되는 까닭이 있어서다.

| | 일 트랙 | 대화 트랙 |
|---|---|---|
| 보이는 것 | **진행 표시만** | **답변 글자 + 도구 활동** |

⭐ **읽기 전용이라서 안전하다.** `Read`·`Grep` 의 입력은 파일 이름이고 **그게 곧 산출물 이름**
(`REQ-014.md`)이라 개발 언어로 안 읽힌다.

⛔ **같은 규칙을 일 트랙에 쓰지 마라.** 거기는 `Edit` 의 입력이 **HTML 조각**이라 그대로 샌다.
`planner-one-flow` 의 「기획자는 HTML 을 보지 않는다」가 깨진다.

**번역 장치를 만들지 않는다** (2026-08-15 병주 결정). 도구 활동을 사람 말로 옮기지 않고
있는 그대로 흘리되 줄만 다듬는다. 옮기기 시작하면 도구가 늘 때마다 옮길 말이 는다.

## 표는 하나다

`ai-run` 이 예약해 둔 「지시 보관」 표를 **처음부터 두 트랙을 담게 그린다.** 새 표를 따로 만들지 않는다.

| 무엇 | 두 트랙 공통인가 |
|---|---|
| 일 열쇠 · 순번 · **트랙** · 누가(사람/AI) · 본문 | **공통** |
| 실행 ID · 스냅샷 순번 | **일 트랙만** (대화는 비어 있다) |

⭐ **소급이 없다.** 이 표는 계획 2 Task 4 에 있고 **그 Task 가 아직 얼려 있어 만들어지지 않았다.**
지금 정하면 고칠 것이 없다. 얼기 전에 만들어졌으면 마이그레이션이 한 회차 들었다.

⚠️ **열 이름은 영문 snake_case 이고 뜻은 한글 COMMENT 로 적는다** (`data-model.md` 의 규칙).
실제 DDL 은 이 문서가 아니라 구현 계획이 쓴다.

## 안 바꾸는 것

**여기 적힌 것을 이 문서를 근거로 고치지 마라.**

- **끝 다섯 갈래** — 성공 · 실패 · 시간초과 · 그만둠 · 자격끊김. 대화 트랙도 같은 다섯으로 끝난다.
  ⚠️ **다만 대화 쪽은 성공 아닌 넷에서 되돌릴 것이 없다** — 고친 파일이 없으니 그냥 그 턴이 실패한 것이다.
  ⛔ **「한도」를 값으로 더하지 마라** — 갈라낼 수 있는지 못 쟀고 일부러 뺀 자리다
- **자동 되돌리기** — `ai-run` 것이다
- **`AiRunWorker.java:102` 의 자격 자리 수명** — 실행마다 깔고 `finally` 로 지운다. 그대로 둔다
- **일 트랙의 `--output-format json`** — 한 덩어리로 받아 한 번에 파싱. 스트리밍은 대화 트랙에만
- **「한 일에 하나」 유일 제약** — 일 트랙에만 건다
- **큐를 안 둔다** — 대화가 늘어도 근거가 안 바뀐다. 부딪히는 자리는 여전히 서버 하나뿐이다

## 무엇으로 증명하나

- **대화가 파일을 못 고친다** — ⛔ **대역이 아니라 실물로 한 번 잰다.**
  도구 제한이 실제로 먹는지는 대역으로 증명이 안 된다
- **되돌린 지시가 다음 프롬프트에 안 들어간다**
- **「여기로」가 파일과 문맥을 같은 지점으로 옮긴다** — 둘 중 하나만 움직이는 것을 잡는다
- **적용 전까지 초안이 안 바뀐다** — 대화를 열 번 해도 본문이 그대로다
- **대화 트랙은 「한 일에 하나」에 안 걸린다** — 일 트랙이 도는 중에도 대화가 열린다
