# 미리보기가 어느 기관으로 그리나

> **이 문서가 답하는 질문 하나: 한 화면을 제주로 볼 것인가 익산으로 볼 것인가, 그리고 무엇을 갈아야 그렇게 되나.**
>
> 날짜 2026-08-22 · 기준 추출기 `80530f9` · 기획 레포 `568586b`.
> 계기는 추출기 회신 #5(「기관 스킨 축이 섰다. 스타일 전환은 그쪽 몫이다」)와, 그것을 받다가 찾은 실물 고장이다.

## 1. 무엇이 틀어져 있나 — 실측

브라우저로 직접 보고 잰 것이다(2026-08-22 · 프로젝트 `0000001` 「제주/익산_지역화폐」).

| 무엇 | 실측 |
|---|---|
| FRD-027 | **적용 대상이 제주**인데 웹뷰 초안이 **익산 스타일**(`assets/css/iks/ui.base.css`)로 그려진다 |
| 갈래 화면 | `SolutionScreen.previewPath(null)` 이 **`variants` 의 첫 기관**을 집는다 — 가나다순이라 언제나 `iksan` 이다. 제주 사업에서도 익산 갈래를 연다 |
| 적용 구분 코드 | `adk_builder_project_facet` = `iksan`·`jeju`. **추출기 `manifest.systems[].skins` 의 열쇠와 글자가 같다** |
| 스킨 실물 | `webview`·`online-pg` = `{iksan: …/css/iks, jeju: …/css/tnj}` · `portal` = `{jeju: …}` 하나뿐 · 백오피스 셋 = `{}` |
| 색인 | `we-adk-index/6` · `counts.skinScreens 282` (webview 252 iksan · online-pg 8 jeju · portal 22 jeju) |

⛔ **css 가 안 붙는 고장은 아니다.** 목업 651장의 링크를 디스크에서 전수 대조했고 깨진 스타일시트는 **0건**이다.
미리보기 응답도 전부 200 이다(`885b7eb` 의 `<base href>` 주입이 FRD 초안의 상대경로를 이미 세웠다).
**틀린 것은 「안 보이는 것」이 아니라 「다른 기관으로 보이는 것」이다.**

## 2. 지렛대가 둘이다 — 경계는 추출기가 실측으로 그었다

| 무엇이 갈리나 | 누가 처리하나 | 어떻게 |
|---|---|---|
| **마크업** (웹뷰 11장) | **추출기** | `core/<시스템>/variants-<기관>/<화면ID>.html` 을 따로 낸다. 빌더는 **파일을 고른다** |
| **스타일** (웹뷰 252 · online-pg 8 · portal 22) | **빌더 ← 여기** | 목업은 한 장뿐이다. 빌더가 **렌더 시점에 스킨 폴더를 치환한다** |

252장을 기관마다 한 장씩 내는 길은 추출기가 이미 버렸다(원본과의 바이트 대조가 사라지고, 기저 html 과 갈래는 상호배타라 웹뷰 전 화면이 갈래가 된다).

## 3. 기관은 한 값이다 — 파라미터 하나가 지렛대 둘을 다 태운다

⭐ **`기관` 하나만 정하면 된다.** 갈래 화면이면 파일이 갈리고, 스킨 화면이면 css 폴더가 갈린다.
**두 갈래를 부르는 쪽이 구분하지 않는다** — 그것이 이 설계의 값이다.

정하는 차례:

1. **사람이 화면에서 고른 값** — 솔루션 목업 상세의 기관 탭(`?variant=`)
2. **그 FRD 의 적용 대상** — 하나면 그것 (`adk_builder_frd_facet` 의 이름 → `adk_builder_project_facet` 으로 코드를 찾는다)
3. **프로젝트의 적용 구분** — 하나뿐이면 그것
4. **못 정하면 안 갈아낀다** — 색인이 그린 그대로 둔다

⛔ **기본 기관을 지어내지 마라 (추출기 회신 #5 의 물음 ②).** 넷째 칸이 「익산으로 친다」가 되면
online-pg 8장이 통째로 틀린다 — **방향이 시스템마다 반대다.**
⚠ 갈래 화면만은 예외다. **기저 html 이 아예 없어서**(있으면 그쪽 `A-1` red) 반드시 하나를 골라야 한다 —
못 정하면 지금처럼 첫 기관을 연다. **그 자리는 「모른다」를 그릴 수 없다.**

## 4. 치환 절차 — 추출기가 준 3단계를 그대로 벤다

목업 `core/webview/pages/wv-x.html` 을 `jeju` 로 그린다고 하자.

1. `href`·`src` 를 **목업이 있는 폴더 기준으로 풀어 저장소 뿌리 기준 경로**로 만든다.
   `../assets/css/iks/ui.base.css` → `core/webview/assets/css/iks/ui.base.css`
   (질의문자열 `?ver=…` 은 떼고 보고 나중에 도로 붙인다. `http(s)://`·`//`·`/…`·`data:`·`tel:` 은 이 레포의 사실이 아니라 안 건드린다.)
2. 그 경로가 **`skins[<어느 기관이든>]` 아래면**(경계는 `/`) 그 접두를 `skins["jeju"]` 로 바꾼다.
   → `core/webview/assets/css/tnj/ui.base.css`
3. 목업 폴더 기준으로 **다시 상대화**해 링크에 쓴다. → `../assets/css/tnj/ui.base.css`

⭐ **색인의 `screens[].skin` 을 읽지 않는다.** 「지금 어느 기관인가」는 **링크 실물이 이미 말한다** —
그 화면이 부르는 스킨은 많아야 하나임을 그쪽 `SKIN-1` red 가 보증한다.
그래서 **「칸이 없으면 전환 대상이 아니다」가 저절로 지켜진다** — 걸릴 링크가 없으면 손댈 것도 없다.
칸을 안 읽으니 색인이 한 판 늦어도 화면이 틀리지 않는다.

## 5. 안 하는 것 — 없는 보증을 있다고 적지 않는다

- **인라인 `<style>` 안의 `url()` 과 `srcset` 은 안 본다.** 요소의 `href`·`src` 만 본다 (추출기 검사기와 같은 눈이다).
- **스킨 폴더 밖의 기관 자산은 못 고친다.** `wv-modal-history-card` · `wv-modal-store-pay-info` 두 장이
  제주 그림(`tnj-card-1.png` 등)을 마크업에서 직접 부른다 — 소스가 박아 둔 것이고 `SKIN-3` review 가 이름을 부른다.
  **css 를 갈아도 그 그림은 안 갈린다.** 판정을 적을 칸은 아직 양쪽 어디에도 없다.
- **`skins[대상 기관]` 이 없으면 그대로 둔다.** `portal` 은 제주 스킨만 실재한다 — 없는 익산을 지어내지 않는다.
- **저장본을 안 고친다.** 치환은 **응답에서만** 한다. DB 의 초안 html 과 클론의 목업 파일은 한 글자도 안 바뀐다 —
  기획 레포로 밀 때 우리 손자국이 섞이면 안 된다.

## 6. 어디에 붙나

| 문 | 무엇을 하나 |
|---|---|
| `SolutionPreviewController` | html 을 낼 때만 치환한다. 자산(css·이미지) 요청은 **그대로 낸다** — 이미 갈린 주소로 들어온다 |
| `FrdController.preview` · `historyPreview` | `<base href>` 주입에 이어 같은 치환을 건다. 기준 폴더는 base 가 가리키는 그 폴더다 |
| `SolutionMockupController` | 기관 탭을 **갈래 화면뿐 아니라 스킨 화면에도** 띄운다. 고른 값은 지금 쓰는 `variant` 파라미터를 그대로 쓴다 |
| `PlanningManifestReader` | `systems[].skins` 를 읽어 낸다. **`iks`·`tnj` 라는 글자를 빌더 코드에 두지 않는다** — 그 매핑은 사업 지식이고 그것을 우리가 쥐면 빌더가 g2c 를 아는 것이 된다 |

## 7. 시험이 무엇을 잡나

- 익산 목업을 제주로 그리면 `iks` → `tnj` 로 갈리고 **질의문자열이 살아 있다**
- 절대주소·`http(s)`·`tel:`·`data:` 는 **안 갈린다**
- 스킨 폴더 **밖** 자산(`assets/images/card/tnj-card-1.png`)은 **안 갈린다** — SKIN-3 두 장이 그대로 남는 것을 시험이 굳힌다
- `skins` 가 `{}` 인 시스템(백오피스)과 대상 기관이 없는 시스템(portal 익산)은 **원문 그대로**
- 갈래 화면은 **고른 기관의 파일**을 연다 — 못 정할 때만 첫 기관
- 제주 FRD 의 초안 미리보기가 `tnj` 로 나온다
