# 갱신된 화면 자료에서 제출 가능한 화면설계서를 어떻게 만드는가

> 이 문서가 답하는 질문 하나: 화면 HTML·화면 MD·IA를 화면별 화면설계서로 만들고 개정 관리하려면 Builder가 무엇을 해야 하는가.

## 제품 계약

- 화면설계서는 그린존의 공식 산출물이다. 개발이 파일로 보내지 않는다.
- 정본 입력은 클론된 기획 저장소의 화면 HTML·화면 MD·IA다.
- 목록의 한 행과 문서의 기본 단위는 `(프로젝트, 시스템, 화면 ID)`다.
- 상세 화면에 들어갔을 때 현재 정상본이 없거나 입력 지문이 달라진 경우에만 자동으로 만든다.
- 사용자는 생성 방식·프롬프트·근거 파일 경로·입력 지문을 보지 않는다.
- 생성·재생성·일괄 생성 버튼은 두지 않는다. 만드는 중에도 직전 정상 개정판은 유지한다.
- 첫 범위는 추출된 기본 화면과 `manifest.json`·`index.json`에 명시된 변형이다. 탭·팝업·단계별 상태를 추측해 조작하지 않는다.

## 문서 구성

한 개정판에는 다음을 고정한다.

1. 화면 개요: 화면명, 시스템, 화면 ID, IA 메뉴 경로, 적용 구분
2. 화면 이미지: 1600px 기준으로 렌더한 정적 캡처
3. 화면 요소 설명: 이미지의 번호와 일치하는 영역·항목·동작·검증·결과
4. 화면 이동: IA와 화면 MD에서 확인한 연결 화면
5. 변형: 기관별 파일이 명시된 경우 변형별 캡처와 차이

설명은 구조화 JSON으로 검증한 뒤 Builder Renderer가 HTML을 만든다. AI가 만든 HTML을 그대로 저장하거나 화면에 넣지 않는다.

## 생성 경계

```text
상세 진입
  → 입력 스냅샷과 지문 계산
  → 원자적으로 생성 선점
  → Playwright Java 정적 캡처
  → 구조화 설명 생성·검증
  → HTML 및 A4 가로 PDF 렌더
  → 임시 번들 검증 후 불변 위치로 이동
  → DB 개정판 저장·현재본 승격
```

- Playwright와 같은 버전의 bundled Chromium은 배포 단계에서 설치한다. 앱 기동 중 다운로드하지 않는다.
- 브라우저가 없거나 캡처가 실패해도 서버는 기동 상태를 유지한다. 해당 화면설계서만 `문서 처리 오류`가 된다.
- 브라우저는 클론의 허용된 파일만 읽는다. 외부 네트워크와 페이지 스크립트는 차단한다.
- 클론 밖 경로, 심볼릭 링크 이탈, 허용하지 않은 자산 확장자는 거절한다.
- 캡처 동시 실행은 한 서버에서 하나로 제한한다.

## 저장과 개정

- DB 현재 행은 생성 상태, 생성 ID, 현재 정상 개정판 포인터와 최신 입력 지문을 가진다.
- 개정판 행은 입력 지문, 생성기·스키마 버전, 구조화 내용, 검증된 문서 HTML, 번들 상대경로와 체크섬을 가진다.
- PNG·PDF는 `builder.data-root` 아래 개정별 불변 번들에 둔다. DB에는 절대 경로나 바이너리를 넣지 않는다.
- 생성은 고유 임시 디렉터리에서 수행한다. 모든 파일이 준비된 뒤 원자적으로 옮기고 DB 현재본을 승격한다.
- 늦게 끝난 이전 생성은 새로운 생성의 현재본을 덮을 수 없다.

## 화면 계약

목록은 현재 Builder 목록 순서를 따른다.

```text
page-head → summary-strip → filter-bar → state-panel 또는 table-wrap → list-table-foot
```

- 필터는 시스템·문서 상태·화면 검색이다.
- 표는 화면명, 화면 ID, IA 메뉴 경로, 시스템, 문서 상태, 화면 최종 수정, 문서 작성일을 보여 준다.
- 별도 액션 열 없이 화면명 링크로 상세에 들어간다.
- 상세는 화면명과 메타데이터, 생성 상태, 공식 문서, `PDF 내려받기`, `목록으로`로 구성한다.
- PDF는 레이어에 가두지 않고 파일로 내려받는다.

375px에서는 페이지 전체가 아니라 표와 넓은 문서 내용만 가로로 스크롤한다. 필터와 상세 행동은 한 열이 되고, 기존 글자 크기·행 높이·공통 컴포넌트를 유지한다.

## 실패 문구

- 브라우저 미설치: `화면설계서 작성 도구를 사용할 수 없습니다. 관리자에게 서버 설치 상태를 확인해 달라고 요청해 주세요.`
- 입력 없음: `화면설계서 작성에 필요한 화면 자료가 없습니다. 기획 저장소 갱신 상태를 확인해 주세요.`
- 입력 변경: `문서를 작성하는 동안 화면 자료가 변경되었습니다. 최신 자료로 다시 준비합니다.`
- 그 밖의 실패: `화면설계서를 준비하지 못했습니다. 잠시 뒤 상세 화면을 다시 열어 주세요.`

오류가 난 뒤에도 직전 정상 개정판이 있으면 본문은 계속 보여 주되 최신본이 아님을 글자로 알리고 PDF 내려받기는 막는다.
