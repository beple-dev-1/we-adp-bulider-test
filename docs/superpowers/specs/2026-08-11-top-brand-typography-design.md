# Top 명칭·타이포그래피 정렬 설계

## 목적

Builder 목업의 Top 제품명을 `WE-ADP Builder`로 고치고, WE-ADK Admin보다 크게 보이는 기본 글자 위계를 Admin 수준의 업무 화면 밀도로 맞춘다.

## 변경 범위

- 실제 Builder 공통 셸과 목업 공통 셸의 Top 제품명을 `WE-ADP Builder`로 표시한다.
- 본문 기본 글자는 15px로 맞춘다.
- 표와 왼쪽 산출물 메뉴 글자는 14px로 맞춘다.
- 본문 페이지 제목 `h1`은 24px, 절 제목 `h2`는 18px로 맞춘다.
- 버튼과 메뉴 링크의 최소 조작 높이 44px은 유지한다.
- 보조 문구, 배지, 입력 도움말처럼 이미 12~13px 위계인 글자는 이번에 바꾸지 않는다.

## 변경하지 않는 것

- 산출물 메뉴의 10개 항목, 순서, 구분선은 바꾸지 않는다.
- 목업 산출물 메뉴의 현재 `href` 동작은 바꾸지 않는다. 화면 간 연결은 후속 피드백으로 보류한다.
- 색상, 간격, 표 구성, 화면별 카피와 데이터는 바꾸지 않는다.
- WE-ADK Admin 저장소는 비교 기준으로만 사용하고 수정하지 않는다.

## 구현 원칙

공통 셸의 정본은 `src/main/resources/templates/fragments/parts.html`과 `src/main/resources/static/css/shell.css`다. Top 명칭과 타이포그래피를 정본에서 먼저 바꾸고, 정적 목업 사본인 `docs/mockups/_shell.js`에 같은 Top 명칭을 반영한다. 화면별 HTML에는 중복 수정을 만들지 않는다.

글자를 줄여도 접근 가능한 조작 영역은 줄이지 않는다. 메뉴와 버튼은 기존 최소 높이 44px을 유지해 시각 밀도와 조작성을 분리한다.

## 검증

- `python docs/mockups/check_mockups.py`를 실행한다.
- 제품 목업을 데스크톱과 375px 너비에서 렌더해 Top 명칭, 제목 위계, 표 가독성, 가로 넘침을 확인한다.
- 실제 셸과 목업 셸 모두 `WE-ADP Builder`를 표시하는지 확인한다.
- 산출물 메뉴의 항목·순서·링크가 변경되지 않았는지 확인한다.
