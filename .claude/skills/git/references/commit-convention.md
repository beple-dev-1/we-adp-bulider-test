# 커밋 메시지 규약

## 형식

```
[{과업번호}] {TYPE} : {한 줄 요약}
```

- **과업번호** — 산출물(`{outputDir}/works/`·`plans/`)의 과업번호와 같은 값을 쓴다.
  과업번호가 없는 변경(설정·문서 정리 등)은 `[chore]` 처럼 성격을 넣는다.
- **TYPE** — 아래 표에서 고른다. 변경의 **의미**로 정한다. 파일 추가·수정 여부로 정하지 않는다.
- **요약** — 무엇을 바꿨는지 한 줄. 파일명 나열은 하지 않는다.

## 타입

| TYPE | 쓰는 때 |
|---|---|
| `ADD` | 없던 기능·파일을 새로 만듦 |
| `CHANGE` | 기존 동작·구조를 바꿈 |
| `FIX` | 잘못 동작하던 것을 고침 |
| `REFACTOR` | 동작은 그대로, 구조만 정리 |
| `REMOVE` | 기능·파일을 없앰 |
| `DOCS` | 문서·주석만 |
| `TEST` | 테스트 코드만 |
| `CHORE` | 설정·빌드·의존성 |

- `FIX` 와 `REFACTOR` 가 애매하면 **동작이 바뀌었는지**로 가른다. 바뀌면 `FIX` 또는 `CHANGE`.
- 파일 상태(추가/수정/삭제)는 보조 힌트일 뿐이다. 의미가 우선한다.

## 예시

```
[001] ADD : 포인트 한도 조회 API 구현
[014] FIX : 만료 알림 날짜 계산 하루 오차 수정
[020] REFACTOR : 결제 응답 매핑을 단일 함수로 정리
[chore] CHORE : 린트 규칙 추가
```

## 본문

변경이 여러 항목을 포함하면 제목 한 줄 + 빈 줄 + 본문 목록으로 쓴다.

```
[017] CHANGE : 웹뷰 진입 파라미터 규격 정리

- 요청부 식별자를 UUID 기준으로 변경
- 미사용 파라미터 2개 제거
- 관련 테스트 갱신
```

## 커밋 전 체크리스트

1. 변경 파일이 이 과업 범위인가. 딴 과업 파일이 섞여 있지 않은가.
2. `/code-review` 를 거쳤는가.
3. 시크릿·개인정보·로컬 전용 파일이 포함되지 않았는가.
4. 산출물 디렉터리(`outputDir`)가 추적 대상에서 빠져 있는가.
5. 소스와 하네스를 다른 레포에 두는 환경이면, 이 커밋이 한쪽만 담고 있는가.

## 도구 주의

- 한글 메시지가 깨지는 환경에서는 메시지를 UTF-8 파일로 저장한 뒤 파일로 전달한다
  (`git commit -F {파일}` / `svn commit -F {파일} --encoding UTF-8`).
- VCS 실행 파일이 PATH 에 없을 수 있다. 실패하면 전체 경로로 재시도한다.


---

## 비ASCII 메시지 (윈도우) — 도구마다 방향이 반대다

한글 커밋 메시지가 **조용히 깨진다.** 종료 코드는 0 이고, 터미널 출력도 코드페이지 때문에
어차피 깨져 보여 **눈으로는 정상과 구분이 안 된다** (2026-09-01 실측).

| VCS | 넣는 법 |
|---|---|
| `git` | `git commit -F 파일` 이 UTF-8 을 그대로 읽는다. 파일 방식이 안전하다 |
| `svn` | `-m` 인라인은 정상. **`-F` 는 시스템 코드페이지로 읽으므로 `--encoding UTF-8` 을 반드시 붙인다** |

```bash
svn commit -F 메시지.txt --encoding UTF-8      # 붙이지 않으면 깨진다
```

**`rules/testing.md` 의 "한글 본문은 UTF-8 파일로 보낸다" 를 여기에 그대로 옮기지 않는다.**
그 규칙은 **HTTP 요청 본문(`curl`)** 에 대한 것이고, svn 커밋 메시지는 **방향이 반대**다.
일반 규칙으로 읽고 적용하면 정확히 깨지는 경로로 간다.

### 넣은 뒤 확인한다

```bash
svn log -r {리비전} --xml > /tmp/m.xml     # 파일로 받는다
grep -c "기대하는 한글 문구" /tmp/m.xml    # 0 이면 깨진 것
```

- 터미널에 그대로 출력해 눈으로 보는 것은 판정 근거가 못 된다.
- 이미 깨진 뒤라면 `svn propset --revprop -r {리비전} svn:log -F 파일 --encoding UTF-8 {저장소URL}` 로 고친다.
  단 저장소에 `pre-revprop-change` 훅이 있어야 한다 — **사내 서버면 관리자 권한이 필요하다.**
  그래서 **넣을 때 제대로 넣는 것이 유일하게 값싼 길이다.**
