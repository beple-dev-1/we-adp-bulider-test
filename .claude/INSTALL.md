# 설치 후 할 일

1. 이 `.claude` 폴더가 **프로젝트 최상위**에 있는지 확인한다.
   `ls -a` 로 소스 폴더와 같은 자리에 보이면 맞다.
2. **그 프로젝트 폴더에서** Claude Code 세션을 연다 — 폴더로 이동한 뒤 `claude` 를 실행한다.
3. 세션에 `/setup` 을 입력한다.

무엇을 채울지는 `/setup` 이 묻는다. 미리 준비할 것은 없다.

- 첫 단계(탐지)는 진행 표시 없이 시간이 걸린다. 멈춘 것이 아니므로 기다린다.
- `/setup` 이 명령 목록에 안 보이면 세션을 연 위치가 다른 것이다. 프로젝트 폴더에서 다시 연다.
- 자세한 설명은 관리자가 함께 보낸 사용자 가이드에 있다.
